## ハマった点と対処
- Node.js 18 では Next.js が動かない → nvm で Node 20 に。
- `@/lib/api` が見つからない → tsconfig の paths を ["./app/*"] に変更(方法B)。変更後サーバー再起動。
- globals.css は frontend/app/ の中にある(backendのappと紛らわしい)。
- /entry/[id] が「読み込み中」で止まる → CORS未設定が原因。main.py に CORSMiddleware 追加で解決。
- 検索結果でタイトルが長いと近さ%が消える → %を .entry-title の外に出して解決。

## 学んだ概念(Next.js)
- フォルダ構造 = URL構造。page.tsx は予約ファイル名(これがあるとページになる)。
- 他の予約名: layout.tsx / loading.tsx / error.tsx / not-found.tsx
- 動的ルート: フォルダ名を [id] のように角括弧で囲むと「変数の穴」になる。
  useParams() の params.id で受け取る。1ファイルで無限のURLに対応(Twitter/YouTube方式)。
- "use client" : ボタン操作や状態変化のある画面に必要な宣言。
- useState=状態の箱 / useEffect=表示時の処理 / value+onChange=入力の定番ペア。
